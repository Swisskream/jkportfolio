<h2>☁️ Cloud Implementation</h2>

<p>This site is fully deployed and hosted using AWS cloud services:</p>
<ul>
  <li><strong>Amazon S3</strong> – Hosts the static frontend assets</li>
  <li><strong>CloudFront</strong> – Distributes content globally via CDN</li>
  <li><strong>Route 53</strong> – Manages DNS for the custom domain</li>
  <li><strong>AWS Certificate Manager</strong> – Provides HTTPS encryption</li>
</ul>
